# ADR-008: Workspace-Based Multi-Tenancy

**Status:** Accepted

## Context

PulseFlow serves individual developers as well as teams and organizations.

The database must support personal and organizational ownership while keeping tenant data isolated.

## Decision

Use a common workspace abstraction.

A workspace can represent either a personal workspace or an organization workspace.

Projects, queues, jobs, API keys, and related resources will be associated with the appropriate workspace scope.

Membership and role-based authorization will control access to organizational resources.

## Consequences

- Consistent ownership model across individual and team accounts.
- Simplifies resource authorization.
- Requires workspace-scoped queries and authorization checks.
- Database-level row security remains a separate decision to evaluate before production.
