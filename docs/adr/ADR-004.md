# ADR-004: PostgreSQL as the System of Record

**Status:** Accepted

## Context

PulseFlow stores users, workspaces, projects, queues, jobs, attempts, events, logs, and scheduling information. These records require durable storage and transactional consistency.

## Decision

PostgreSQL will be the primary system of record.

Prisma will provide database access and schema management.

Redis will not replace PostgreSQL as the durable source of truth for business records.

## Consequences

- Strong relational integrity.
- Transactional support for critical operations.
- Indexing and query optimization will be important as job volume grows.
- Database migrations must be reviewed and version-controlled.
