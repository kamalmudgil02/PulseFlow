# ADR-002: Independently Deployable Applications

**Status:** Accepted

## Context

The web interface, API, and background job processing have different runtime requirements and scaling characteristics.

## Decision

Organize the system into three applications:

- `apps/web`: Next.js frontend.
- `apps/api`: NestJS API.
- `apps/worker`: NestJS background worker.

Shared domain contracts and utilities will live in reusable packages.

## Consequences

- Each application can be built and deployed separately.
- Workers can scale independently from the API.
- Shared contracts reduce duplicated types.
- Cross-application compatibility must be managed carefully.
