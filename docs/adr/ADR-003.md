# ADR-003: Core Application Technology Stack

**Status:** Accepted

## Context

PulseFlow needs a maintainable TypeScript-based stack suitable for a production-oriented full-stack application.

## Decision

Use the following technologies:

| Layer                | Technology     |
| -------------------- | -------------- |
| Frontend             | Next.js        |
| Backend API          | NestJS         |
| Background worker    | NestJS         |
| Language             | TypeScript     |
| Database access      | Prisma         |
| Primary database     | PostgreSQL     |
| Queue infrastructure | Redis + BullMQ |

Package manager and exact version choices must be recorded in implementation configuration before development begins.

## Consequences

- Consistent TypeScript usage across applications.
- Shared contracts and validation types are possible.
- Developers must maintain compatible package versions.
- Framework conventions should be followed rather than creating unnecessary abstractions.
