

# PulseFlow

PulseFlow is an advanced distributed job processing platform.

## Technology Stack

- Next.js

- NestJS

- TypeScript

- PostgreSQL

- Prisma

- Redis

- BullMQ

- [Socket.IO](http://Socket.IO)

- Docker

- OpenTelemetry

## Architecture

Modular monolith with independently deployable API and worker processes.
